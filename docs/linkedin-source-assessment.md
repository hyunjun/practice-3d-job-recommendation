# LinkedIn 채용 자료 수집 검토 — 2026-09-26

2026-09-26에 수행한 검토를 로컬 자료 삭제 전인 2026-09-28에 보존한 기록입니다. 이번 정리 중 사이트를 다시 조회하지 않았습니다.

일반 소개 페이지 한 곳과 정책·API 문서 세 곳만 확인했습니다. 이번 응답에서 로그인 차단·403·429가 발생했다고 보고하지 않으며, 개별 공고 검색·페이지 순회·본문 수집은 실행하지 않았습니다.

당시 프로젝트에는 LinkedIn이 부여한 크롤링 허가나 조회·보관·표시 권한을 포함한 데이터 계약이 없었습니다. HTTP 200이나 공고 게시 API의 존재만으로 별도 수집기를 도입하지 않았으며, **LinkedIn에서 추가한 개별 공고는 0건**입니다. 필요한 권한이 확보되면 그 범위와 호출 제한을 기준으로 검토할 수 있습니다.

데이터 보충은 회사의 공식 커리어 페이지와 공개 ATS 게시판을 중심으로 진행했습니다. 실제 조회한 회사·제공자를 출처로 기록하며 LinkedIn에서 가져온 자료로 표시하지 않습니다. 이후 확장 내용은 [출처 조사](source-survey.md)와 [지역·산업별 출처](regional-industry-sources.md)에 있습니다.
