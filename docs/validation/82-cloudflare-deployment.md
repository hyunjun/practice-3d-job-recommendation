## 구현한 동작

Workers Static Assets가 화면을, SQLite Durable Object가 저장된 공고를 제공합니다. GitHub Actions가 매시 17분·47분에 회사별 수집 주기와 재시도 대기 정책에 따라 수집합니다. 처음 열기·새로고침·지구 이동은 방문자의 요청에서 수집을 시작하지 않습니다. R2·Containers는 활성화하지 않습니다.

공개 공고·목록 확인·관측 자료와 비공개 수집 체크포인트를 같은 버전으로 발행합니다. 업로드 도중에는 이전 자료를 제공하고, 청크 완전성과 부모 버전을 확인한 뒤 SQLite 트랜잭션으로 전환합니다. 복구 시 이전 공개 자료와 최신 수집 체크포인트를 결합해 누적 관측·실패 이력을 되돌리지 않습니다.

큰 응답은 검증된 gzip 조각을 한 번에 최대 64 KiB씩 해제하며 소비자를 기다립니다. 화면은 예약 수집 시각과 표시 중인 자료 버전을 안내하고, 보관이 끝난 관측 버전에는 새로고침을 안내합니다. 프로필·이력서·저장 공고·메모는 발행 API로 보내지 않습니다. 운영 방법과 한도는 [Cloudflare 운영 문서](../cloudflare.md)에 설명합니다.

이 구현 설명은 실제 검사 통과나 배포 완료를 뜻하지 않습니다.
