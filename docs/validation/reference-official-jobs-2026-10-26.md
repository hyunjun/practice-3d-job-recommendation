## 변경과 적용 근거

승인된 설계의 SHA-256은 `f1234e860709cb1eb93fc552d10f17e9e5e45a342d864925e535cf071630aa37`이다. 주 구현 담당과 GPT-6 Astra(요청 reasoning `max`) 검토를 거쳤으며 독립 테스트 담당이 검증을 실행한다. 이후 사용자 지시에 따라 Fable은 제외됐다. 과거 차단으로 미수신한 검토는 승인으로 취급하지 않는다.

## 발견한 문제와 수정

전체 검사에서 드러난 아래 문제를 각각 기록하고 동일한 사용자 동작 계약을 유지하도록 수정했다.

- 당근 국가 표시는 기존 한국어 계약상 `대한민국`이다. 영어 국가명을 기대하던 검사를 보정했다. 검색·저장·상세·원문 링크·요청 간격 검사는 유지했다.
- 회사 조사 검사는 전체 132개 수집이 완료되기 전에 기존 집단의 결과를 검사하고 있었다. 전체 완료를 선행 조건으로 명시했으며 기존 집단의 63/64개 기대값과 제한 시간은 유지했다.
- 출처 집합 검사에 새 두 회사의 정상 빈 게시판을 추가했다. 기존 세 출처의 항목과 상태는 유지했다.
- 공개 수집 생명주기 가상 자료에서 새 두 회사의 신선한 빈 캐시가 누락되어 예상하지 않은 robots 요청이 발생했다. 기존 129개 캐시의 순서·시각·원시 필드를 유지하고 새 두 회사만 추가했다. Booking 지연과 최초 한 URL·최종 두 URL 기대값, 취소·재참여·저장된 항목만 보는 재시작·개인정보 검사를 유지했다.

마지막 수정은 source06에서 source07로 바뀐 두 테스트 파일에만 해당한다. 나머지 618개 파일은 동일하다. 코드 합의 SHA-256은 `70804a94bd721227bdcb4f3c2ea74d35855dae1e8c22d8040558d76f07ff8f98`다.

GO06은 취소된 부분 실행, GO08·GO09·GO10은 실패한 부분 실행으로 보존한다. GO10 사전 검사는 11개 통과·1개 실패·1개 미실행이며 전체 production과 development는 실행하지 않았다. source07로 수행한 GO11의 사전 검사 13개가 이 수정 범위를 새로 확인했다.

## 관측과 한계

GO11의 생명주기 검사는 1440px·320px에서 각각 통과했다. 최종 132개 회사·게시판과 공고 4개, Booking의 정확한 두 가상 요청, 저장한 Notion 공고의 메모·상태, 재시작 후 캐시 바이트 보존을 확인했다. 기존 129개의 원시 메타데이터·공고 필드는 보존되지만, 로딩 중 보강되는 Stripe·Notion의 파생 정규화 필드는 원시 필드 동일성 주장의 범위에 포함하지 않는다.

13개 사전 검사의 원시 step 4,824개를 검토했다. 성공한 polling 안의 실패 샘플 65개는 남겨 두며 모두 성공한 요청이라고 표현하지 않는다. 브라우저 progress 로그의 204·`net::ERR_ABORTED` 사건 14개 역시 성공 응답으로 바꾸지 않는다. 검사 결과의 재시도나 전역 오류와는 구분한다.

환경·보관 도구의 문제도 제품 검사와 구분했다. 포트 검사는 별도 실제 7사례, 심볼릭 링크를 포함한 보관 처리는 14사례로 검증했다. GO06의 Cloudflare 메타데이터 조회 가능성 때문에 해당 실행의 원격 호출 0회 주장을 철회했으며, 이후 명시적으로 조회를 비활성화해 scheduled UI를 다시 검사했다. 개별 요청의 wire 기록이 없는 과거 실행의 횟수·HTTP 상태는 단정하지 않는다.

GO11 사전 단계에서 완료된 fixture 프로세스 21개의 종료 코드 0과 기본 서버의 SIGKILL을 구분한다. 정상적인 Miniflare.dispose나 전체 실행의 모든 프로세스 종료를 이 사전 단계 결과로 주장하지 않는다.

전체 production 원시 step은 74,939개이며, 성공한 상위 polling 그룹 512개 안의 실패 샘플 900개는 그대로 남긴다. 해당 단계의 13,450개 보관 항목을 대조했고, fixture 124회(80개 기록 파일)의 종료 코드 0과 기본 서버 PID 99660의 SIGKILL을 구분했다.

Development는 2026-10-25 16:09:15~16:23:32 UTC에 원래 8개 파일·39개 검사를 각각 한 번 수행해 통과했다. 원시 step 11,020개 중 실패 샘플 153개는 성공한 상위 polling 그룹 54개에 속하며, 개별 결과·전역 오류나 테스트 재시도는 아니다. stderr의 219-byte Vite `server.hmr` deprecation 경고는 그대로 보존했다.

최종적으로 소스 620개와 고정 실행 파일 83개, 전체 보관 항목 29,222개(일반 파일 21,896개·1,434,532,268 bytes, 루트 포함 디렉터리 1,775개, 링크 원문 5,551개), journal 14개를 대조했다. 실제 실행 도구 session73176은 종료 코드 0을 반환했다. Main은 스냅샷 707개와 시작 기록에서 1,108개 문자열 식별자를 재구성했고, 이를 실제 시작 시각으로 정규화한 1,106개 프로세스 식별자가 남아 있지 않음을 확인했다. 이는 기록된 소유 프로세스의 범위이며 시스템 전체에 대한 보장은 아니다.

작업용 잠자기 방지 프로세스는 실행 전후 동일했고 종료 후 해제됐다. 약 3,537초 실행 구간과 겹치는 2,071개 전원 기록에 Sleep·Wake·DarkWake 사건은 없었다. 전체 fixture의 종료 코드 0인 실행 194회와 기본 서버 세 개의 SIGKILL, listener 조회의 lsof 종료 코드 1 기록 303개는 각각 구분해서 보존한다. 정상적인 기본 서버 종료나 모든 OS 프로세스·포트·외부 통신의 부재를 주장하지 않는다.

## 운영 반영 및 마무리

아직 실제 신규 공고의 수집·발행·공개 화면이나 자동 schedule 실행을 이번 변경의 근거로 확보하지 않았다. 예비 조사에서 본 원시 카드 수를 새로 제공되는 공고 수로 보고하지 않는다.

남은 작업은 합의된 선택적 발행 근거 파일 기능의 별도 구현·검증, 실제 새 두 출처의 완전한 수집, 기존 공개 데이터와 비교한 신규 ID·정규 URL 확인, 전체 132개 출처의 실제 발행 용량·가용성 확인, 운영 화면과 후속 자동 발행 확인이다.

이 기록의 보존 범위는 검증한 출처 어댑터·회귀 검사와 로컬 검증 결과다. 운영 수집기·workflow 반영과 전체 목표의 임시 자료 정리는 후속 작업으로 남아 있다. 필요한 증거를 보존하기 전에 검증 자료를 삭제하지 않는다. 최종 보존 단계에서 재생성 가능한 임시 산출물을 정리하고, 다시 얻을 수 없는 수집 원본·관측은 이유와 위치를 별도로 기록한다.
